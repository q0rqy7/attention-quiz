# 🧠 MindFocus — Тест внимания: Кто управляет твоим вниманием?
### 🎓 University & Classroom Edition

Современное интерактивное веб-приложение для индивидуальной диагностики цифрового фокуса и **проведения групповых сессий в университете (в стиле Quizizz / Kahoot)** с защищённой панелью преподавателя и выводом графиков на проектор.

---

## ✨ Ключевые возможности

### 👤 Для студентов (`index.html`):
1. **Подключение к сессии (Quizizz-Style):**
   - Ввод имени и 6-значного PIN-кода комнаты (или автоматический вход по ссылке `?pin=582-104`).
   - Можно также проходить индивидуально без сессии.
2. **Apple Liquid Glass & Dark Neo-Glassmorphism:**
   - Премиальная светлая тема в стиле Apple Frosted Glass (полупрозрачные молочные стекла, мягкие тени, строгая типографика, отсутствие темных смесей на кнопках).
   - Тёмная кибер-тема с неоновыми градиентами и эффектом свечения.
   - Быстрый переключатель тем в шапке.
3. **13 выверенных вопросов:**
   - 100% ручной переход (выбор фиксируется, переход к следующему вопросу только по клику на кнопку «Далее»).
   - 5-минутный обратный отсчет таймера с предупреждениями.
   - Синтезированные звуковые эффекты (Web Audio API) с возможностью отключения.
4. **Результаты и общая диаграмма группы:**
   - Персональный диагноз (🔴 Тревожный радар, 🟠 Слабый тормоз, 🟡 Автопилот, 🟢 Смешанный).
   - 3 шага рекомендаций.
   - **Интерактивная диаграмма группы (Chart.js):**
     - 🍩 **Круговая (Donut / Pie)** — ОСНОВНАЯ диаграмма
     - 📊 **Столбчатая (Bar)**
     - 🕸️ **Радар качеств (Radar)**
   - Кнопка системного обмена («Поделиться») и копирования ссылки на комнату.

---

### 👨‍🏫 Для преподавателя и организатора (`admin.html`):
1. **Защита доступа:**
   - Панель защищена паролем (по умолчанию: `1234`, настраивается в панели).
2. **Управление комнатой:**
   - Генерация уникального PIN-кода (например, `582-104`).
   - Кнопка быстрого копирования ссылки для группы.
   - **Режим проектора (Full Screen)** для вывода на экран в аудитории.
3. **Lobby в реальном времени:**
   - Отображение подключенных студентов и тех, кто уже завершил тест.
4. **Сводная аналитика аудитории (Chart.js):**
   - Переключение между круговой, столбчатой и радарной диаграммой.
   - Автоматический подсчёт средних значений FOMO, импульсивности, автопилота и самоконтроля по группе.
5. **Детальная таблица студентов:**
   - Полный список: Имя, Диагноз, баллы, триггеры и время.
   - Быстрый поиск по имени.
   - **Экспорт в CSV / Excel** в 1 клик для ведомостей.
6. **Облачная синхронизация:**
   - Поддержка бесплатного **Firebase Realtime Database** и **Supabase**.
   - Встроенный Peer & Local storage fallback (работает мгновенно без настройки).
