# 🧠 MindFocus — Экспресс-тест: Кто управляет твоим вниманием?

Современное интерактивное веб-приложение для диагностики цифровых привычек, фокуса внимания и зависимости от смартфона.

---

## ✨ Ключевые возможности

1. **Современный визуальный дизайн**:
   - **Тёмная тема (Neo-Glassmorphism)**: глубокий космический фон, стеклянные карточки `backdrop-filter: blur(20px)`, неоновые градиенты и эффект мягкого свечения.
   - **Светлая тема (Minimalist Apple / Notion)**: чистый бело-серый интерфейс, мягкие тени, строгая типографика и выверенные контрасты.
   - Мгновенное переключение тем с сохранением выбора в `localStorage`.

2. **Пошаговый квиз (13 вопросов)**:
   - Плавная смена слайдов с анимацией и индикатором прогресса.
   - Поддержка одиночного выбора с автопереходом и шкалы оценки (1–5 и 1–6).
   - Возможность вернуться назад и изменить ответ.

3. **5-минутный таймер**:
   - Обратный отсчёт `05:00` с визуальным индикатором.
   - Автоматическое предупреждение на последней минуте и пульсация на последних 30 секундах.
   - Автоматическое завершение и расчет результата при истечении времени.

4. **Аудио-эффекты (Web Audio API)**:
   - Процедурный синтез звуков кликов и триумфального аккорда без внешних mp3-файлов.
   - Кнопка включения / выключения звука.

5. **Глубокий алгоритм диагностики (4 архетипа)**:
   - 🔴 **«Тревожный радар» (FOMO)** — вопросы 3, 4, 5 (> 10 баллов).
   - 🟠 **«Слабый тормоз» (Импульсивность)** — вопросы 7, 8, 9 (> 10 баллов).
   - 🟡 **«Автопилот» (Машинальность)** — вопросы 10, 11, 12 (> 12 баллов).
   - 🟢 **«Смешанный»** — сбалансированный профиль.
   - При совпадении нескольких условий вычисляется доминирующий профиль с детализацией по всем шкалам.

6. **Персонализированный разбор**:
   - Три конкретных шага рекомендаций для каждого профиля.
   - 3 шкалы выраженности зон внимания в процентах.
   - Индивидуальный анализ триггеров из Вопросов 1, 2, 6 и 13.
   - Салют конфетти (Canvas Confetti).
   - Кнопка «Скопировать результат» для отправки в мессенджеры.
   - Кнопка «Поделиться в Telegram».
   - Кнопка «Пройти заново».

## 🚀 Как запустить

### Вариант 1: Открытие напрямую в браузере (без серверов)
Просто откройте файл `index.html` двойным кликом в любом современном веб-браузере (Chrome, Edge, Firefox, Safari).

### Вариант 2: Запуск через локальный сервер (Python)
В папке проекта выполните в терминале:
```powershell
python -m http.server 8000
```
И откройте в браузере: `http://localhost:8000`
